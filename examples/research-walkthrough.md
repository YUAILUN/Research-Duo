# 合成案例：方法 A 是否值得进入下一阶段

本案例是作者设计的演示，不是真实数据，也不是对其他技能的盲评。所有数字有明确假设，不构成科学发现。

## 输入与问题重构

SIM-E1：方法 A 只在实验室 X 测量，方法 B 只在 Y；A 的指标均值高 15%。两所实验室的仪器、操作者不同。预算只够一个小型后续研究。原问题：“A 更有效，是否立即扩大应用？”

当前数据同时改变方法与实验室，不能区分方法效应、实验室条件和测量偏差。应改为：“在可比较条件下，A 的优势是否仍存在；用哪个最低成本实验区分解释？”这并未断定 A 无效。


## 三个竞争解释与实验

| 假设 | 原观察为何出现 | 能区分的预测 |
| --- | --- | --- |
| H1 方法效应 | A 改善目标过程 | 同一实验室内可比单位随机分配后仍有差异；跨实验室方向一致 |
| H2 实验室条件 | 环境/操作者造成差异 | 同一实验室内部 A/B 差异缩小，而实验室差异保留 |
| H3 测量偏差 | 仪器、批次或读数方式偏移 | 对同一标准样本盲测/交叉测量时出现系统差异 |

先做标准样本的测量一致性检查；其成本和可操作性需确认。若测量偏差可解释主要差异，先修复测量，再讨论方法效应。若测量可比，优先考虑实验室内随机分配或阻断；同一对象适合交叉测量时检查携带效应，不机械套用交叉设计。

小型研究先确认流程、测量和可区分性。主要终点、最小有意义效应、方差和重复结构未给出，不能编造确证性样本量。获取这些输入后再计算所需精度或功效。

## 决策与压力测试

[排序示例](../skills/research-duo/assets/ranking-example.json)是假设偏好的演示：区分能力 0 表示无法区分当前竞争解释、1 表示针对关键解释；可行性和成本效率也为研究者给定的 0–1 效用。它们不是由论文测得的概率，具体分值需要实际项目重新赋值。

在 .45/.35/.20 权重下，随机先导方案得 .8025，继续积累跨实验室观察得 .67；前者在单个权重 ±20% 时仍第一。直接扩大应用被必要证据条件排除。但把区分能力权重降为 .10、可行性升为 .70、成本效率 .20 时，两者分别为 .715 和 .88，首选翻转。这说明价值目标改变可改变排序，不是科学事实改变。研究者若主要追求识别方法效应，就不能用更容易收集数据的优势代替设计可识别性。

## 概率不足时怎么做

本案没有可信先验或实验似然，不能算出真实 EVSI。先用上面的区分预测与情景。独立的 [robust 教学输入](../skills/research-duo/assets/robust-example.json) 中，全面推进、延后、受限试验的最大遗憾分别为 100、100、65；minimax regret 选受限试验，而 maximin 选延后。分歧来自价值准则和假设效用，必须交给研究者审查，不能把任一规则称为客观答案。

另一个独立的 [VOI 教学输入](../skills/research-duo/assets/voi-example.json) 明确假设两状态等概率，推进效用 +100/-100，延后 0，检验敏感度/特异度均 .8：

- 当前最大期望效用 0；完全信息价值 EVPI=50。
- 有区分力试验 EVSI=30，成本 5，净值 25。
- 无区分力试验 EVSI=0，成本 1，净值 -1。
- 若有区分力试验成本超过 30，延后试验更有利；恰为 30 时与不试验平局。

这些数字验证公式，不补充本科研案例缺失的概率。预算单位和效用点必须通过明确偏好换算。

## 事前分支与结果更新

| 新结果 | 下一步 |
| --- | --- |
| 标准样本出现足以解释差异的系统偏差 | 修复/校准测量，旧方法效应结论暂不支持 |
| 测量可比且同实验室差异存在，区间仍宽 | 记录对 H1 的支持及剩余不确定性，设计有充分信息的独立确认 |
| 差异仅在某实验室存在 | 检查交互机制与适用范围，避免无条件推广 |
| 无差异且估计足够精确，排除有意义效应 | 停止当前优势主张或转向新机制 |
| 无差异但估计极不精确 | 结果未决，比较补充样本的决策价值；不能宣称等效 |
