# 合成教学案例：护士主导的出院随访方案，如何设计研究以评估其对患者自我管理能力的影响？

> 本文为原创合成情景：没有真实患者、医院、访谈或研究结果。下文的人群、流程、时间窗和资源均为教学假设，不是临床建议或经验证的最佳方案。未提供文献支持的机制只作为待检验解释；不预设随访有效，不编造效果、概率或精确样本量。本案例应用 [Research Duo](../skills/research-duo/SKILL.md) 的研究架构师与决策编译器职责，由同一作者顺序完成，不构成独立评估，也不调用 Jev。

## 1. 决策简报：先决定是否值得进入正式效果评价

假设某护理团队拟为成年慢性病患者增加护士主导的出院随访。资源只够一个病区、一支随访小组和一个小型先导周期，暂不具备多中心研究条件。当前选择是：直接扩大实施、先做有对照的可行性研究，或暂缓并修复测量和流程。

**暂定选择：先核实测量与分配条件，再开展有对照的随机先导研究。** 直接扩大实施尚缺效果证据；先导研究主要回答能否交付、能否测准及能否区分解释，不承担确证疗效的任务。最强反对意见是同病区污染和额外接触可能使研究无法识别方案特有作用；若这两个问题不能处理，需调整设计或缩小主张。

| 要素 | 本例事前拟定内容，均待实际团队确认 |
| --- | --- |
| 研究问题 | 对符合条件的出院患者，提供护士主导随访方案相对于常规出院支持，是否改善出院后自我管理能力？ |
| 目标人群 | 同一病区、同一预先限定慢性病种、可完成选定测量的成年出院患者；是否纳入照护者代答须先明确，不能混合患者能力与照护者能力 |
| 干预 | 常规支持加结构化随访：核对自我管理目标、让患者复述行动计划、讨论执行障碍并反馈；拟在出院后第 1、2、4 周联系，记录实际内容、时长和未接通情况 |
| 比较对象 | 同期常规出院支持；研究前记录其具体内容、已有电话随访和组间共同服务，不能把“常规”当作空白 |
| 时间零点 | 出院前完成基线测量后随机分配；随访时间均从出院日计算 |
| 主要终点与时间窗 | 出院后第 6 周自我管理能力总分，允许前后 1 周评估；正式入组前选定适合该病种、语言及使用方式且获准使用的工具，冻结计分规则。工具目前未知，不把自制问卷称为已验证量表 |
| 目标估计量 | 所有被随机分配者中，“提供该方案”相对“提供常规支持”的第 6 周平均分差，按分配组分析并考虑基线分数；不以实际接通者替代全部分配者 |
| 辅助测量 | 第 3 周行动计划掌握情况、第 6 周由独立评估员评分的标准化任务、联系负担和失访原因；均不替代主要终点，也不把模拟任务等同于真实生活行为 |

时间窗和随访次数只是可调整的教学设定。当前问题可能问错在于：自报信心上升是否等于能力改善？先确认工具实际测量的构念；若它只测自我效能，就改写研究问题或改选测量，不能用名称掩盖终点错位。

## 2. 识别检查与设计取舍

工作因果假设是：基线病情、既有能力、家庭支持与就医便利性可能同时影响随访参与和结局；分配方案影响接受的支持，支持再影响能力。额外关注可能影响行为或回答，评估方式也可能影响得分。这是一组教学假设，尚无本地观测支持。

| 设计 | 能回答什么及代价 | 本例选择条件 |
| --- | --- | --- |
| 单组前后比较 | 只能描述变化；自然恢复、常规教育和同期服务变化都可能解释提高 | 可用于流程排练，不能据此归因于方案 |
| 个体随机、同期常规支持对照 | 以分配为比较起点，估计整个服务包的效果；须核查分配执行、差异失访与交叉接受 | 本例暂定首选：独立人员生成并保管序列，完成资格和基线登记后揭示分配；评估员尽可能不知道组别 |
| 按护士或病区整群随机 | 在团队间隔离交付，针对污染问题；需要足够独立群组，分析和样本设计需考虑群内相关 | 当前单病区不具备充分条件；若无法隔离交付，寻求更多群组后重新设计，不能以两个团队冒充充分重复 |
| 非随机同期队列 | 在随机确实不可行时保留比较；需要事前测量共同原因并检查可比范围，仍受未测混杂限制 | 退而求其次；主张降为有条件的关联，不能用统计调整保证因果识别 |

这里的随机方案是拟议设计，不是已满足的事实。患者和交付护士难以盲法，故记录对分组的知晓与猜测，统一结局询问脚本，独立评估员不参与随访。避免按“接通次数”调整主要效果估计，因为接通发生在分配之后；接通情况用于描述交付与探索机制。

冻结主要分析为按分配组比较第 6 周分数、考虑基线并报告差值与不确定区间。失访者不直接计为“未改善”，不只分析完成者；记录两组缺失原因，预先约定缺失数据处理与对不同缺失假设的敏感性分析。若结局因严重健康事件而无法定义，另行约定估计目标和报告方式，不随意填入量表最低分。正式方案需由统计人员复核这些选择。

## 3. 竞争解释：让不同解释预测不同观测

以下解释可以并存；一次观察不能把它们完全排序。没有可信先验，不给成功概率。

| 竞争解释 | 若它主导，预期看到什么 | 区分研究或测量及局限 | 对下一步的影响 |
| --- | --- | --- | --- |
| H1 结构化内容改善能力 | 对常规支持的差异同时出现在自报和独立任务；在接触量相近时，结构化内容仍有额外改善 | 若资源允许，另设等接触量的一般关怀组，与结构化组比较；核查内容执行。任务改善只支持所测能力，不能直接证明某一中介机制 | 若内容增益获得充分支持，再评价保留该内容的资源代价 |
| H2 接触与关注本身起作用 | 结构化组与一般关怀组相近，两者都可能优于常规支持 | 三组比较时匹配预定联系频次和时长，记录实际接触；“未显著不同”不足以认定两组等效 | 若精度足够且额外内容没有有意义增益，转向更简约服务的评价 |
| H3 回答迎合或评估偏差 | 自报得分提高，但独立任务未见相应变化；由交付护士询问时差异更突出 | 用独立且尽可能盲态的评估员、统一脚本和任务评分；检查评估方式。两种测量不一致也可能是构念不同 | 先修复测量并审查构念，不把自报变化直接称为能力提升 |
| H4 选择与差异失访 | 仅完成者分析显示优势，低基线能力或难联系者更多缺失；按分配追踪后优势减弱 | 保存招募与分配日志、基线与失访原因，尝试相同强度的结局追踪并做缺失情景分析；无法排除所有非随机缺失 | 调整可及性与追踪；若关键人群仍无结局，限制适用范围或暂停效果解释 |
| H5 时间变化或共同服务造成改善 | 两组随时间同向变化，组间差异不足以支持额外收益 | 同期对照和常规服务变更日志；历史对照不足以排除同期变化 | 若精度尚不足则未决；若能排除事前定义的有意义收益，停止扩大当前方案 |

最小两组先导可检查 H3、H4、H5 的部分预期，**无法单独区分 H1 与 H2**。其结果只支持或反对整个方案包。若实际决定是“结构化内容是否值得额外培训成本”，等接触量对照就成为关键；宁可延后机制结论，也不把两组研究包装成内容特异性证明。

证据状态截至本教学设计：没有疗效数据，没有真实访谈，没有经过核验的测量工具。为避免合成材料被当作外部事实，分开登记来源与假设。

| ID | 类别与来源定位 | 支持范围、反证与依赖 |
| --- | --- | --- |
| E1 | 仓库事实：[研究协议](../skills/research-duo/references/research-protocol.md)的识别检查与最小区分实验卡 | 支持本例采用识别、竞争解释与结果分支的方法；不支持随访有效 |
| E2 | 仓库事实：[决策协议](../skills/research-duo/references/decision-protocol.md)的原子判断与 VOI 条件 | 支持类型、未知值与计算边界；与 E1 同属仓库方法簇，不算独立效果证据 |
| A1 | 教学假设：一个病区与小型先导预算，见第 1 节 | 尚未核实人力、招募量和对照服务；若不成立须重选方案 |
| A2 | 教学假设：第 3 节 H1–H5 的机制与观测 | 只用于生成可证伪预测；允许共存，不能作为已观察的证据 |
| U1 | 未知：目标构念的工具适配性、许可与解释阈值 | 需要核验工具原始验证研究及使用条件；内部一致性或可获得性本身不回答适配问题 |
| U2 | 未知：招募、污染、实际工时、失访和效果变异 | 需要流程排练与先导数据；无数据时保持未知 |

下表为人工决策记录，不是可直接运行的 JSON；沿用协议的类型和状态。`grounded` 只表示有可追溯依据，不等于临床主张已验证。

| 判断 | 类型与事前判据 | value / status / basis | 依据与含义 |
| --- | --- | --- | --- |
| J1：当前能否声称方案提高能力？ | predicate；true：有可识别、测量适配且精度足够的结果；false：当前没有这些结果 | false / grounded / observed | 本文 E1–E2 与 U1–U2 账本显示目前只有设计；这是材料状态事实，不是“方案无效” |
| J2：能力测量是否适配？ | predicate；true：构念、人群、语言、施测和许可均核实；false：已发现不适配 | null / unknown / inferred | U1 未解决，不以假设补 true |
| J3：能否保持干预分离？ | predicate；true：流程排练表明交付可分离；false：常规组持续接受核心内容且无法控制 | null / unknown / inferred | U2 未解决；须定义什么算核心内容污染 |
| J4：下一步优先动作？ | choice；允许“测量与流程核验”“随机先导”“直接扩大” | 测量与流程核验 / provisional / inferred | E1–E2、A1、U1–U2：低成本核验可改变能否进入先导的决定 |
| J5：单病区资源约束是否适用？ | predicate；true：本例按此设定；false：设定被替换 | true / provisional / assumed | A1；这是教学前提，实际项目需核实 |

依赖链：E1、E2 与 A1、U1、U2 → 可识别且可交付的设计主张 C1 → J2、J3、J4 → D1“先核验，再有条件进入先导”。J1 排除立即宣称有效；J2、J3 是进入当前随机先导方案的必要条件，其他优点不能抵消其失败。这个账本是论证依赖记录，不是因果图。

## 5. 资源有限时最有价值的下一步

**先做一次测量与交付流程排练。** 由团队先检索并核验候选工具原始验证研究、许可和目标人群适配，再用合成患者脚本模拟招募、隐藏分配、随访交付和独立结局评估。必要时在适当授权后做小规模认知访谈；没有真实入组前，不声称已验证实际患者可理解性。

这一步优先于只增加随访电话数量，因为它能淘汰“测错构念”或“无法形成比较”的方案。排练记录护士实际工时、脚本理解障碍、评估员是否被泄露分组和污染路径；同时核实常规支持内容。它不能估计疗效或真实失访率。

通过后才进入两组随机先导：沿用第 1–2 节的人群、时间零点、干预、对照及主要终点，交付和评估职责分开；收集可行性与测量信息，效果估计仅作探索。预算先保留独立结局追踪，若无法覆盖，则调整交付强度或推迟研究。确证性样本量需补齐最小有意义差异、工具变异、预期失访、目标精度或功效及可能的聚类结构；不能把小先导中偶然偏大的效果直接用作唯一依据。

事前由患者代表、护士与统计人员确定可接受工时、缺失、污染与测量负担的阈值，并写明理由；本例缺乏依据，不代填百分比。伦理审查、知情同意及隐私安排是实际入组前需落实的条件，本教学文档不代表已获批准。

## 6. 定性情景、继续/停止条件与翻转证据

没有可信概率、似然或共同效用单位，因此不计算 EVSI，也不填写任意数值的遗憾矩阵。比较以下条件策略，不能称其为数学最优。

| 新证据或情景 | 决定及规则 |
| --- | --- |
| 工具适配、分配与交付可执行，负担在事前阈值内 | 继续随机先导，冻结主要终点、分析和分支；不因流程顺利就扩大服务 |
| 工具主要测信心，或患者无法理解关键条目 | 暂停能力效果评价；改选或验证工具，必要时改写研究问题。J2 与 D1 重审 |
| 常规组持续获得核心干预，职责分离无法解决 | 调整交付或寻求多群组设计；J3 不满足时不继续原比较 |
| 失访集中在难联系或低能力患者，敏感性分析使结论翻转 | 调整可及性和追踪，限制结论；不能只保留接通者。重审 C1 与 D1 |
| 只有自报改善，独立任务不同步 | 优先核查 H3 与测量构念，保留 H1/H2 未决，不直接扩大 |
| 整体方案差异方向有利，但区间仍宽 | 保留不确定性；结合可行性、目标差异与资源决定是否开展充分信息的确认研究，不以先导显著性作为唯一门槛 |
| 可靠、精度足够的结果排除事前定义的有意义收益 | 停止扩大当前方案；若改动核心内容，应作为新假设重新评价 |
| 不确定区间同时包含有意义获益与无收益 | 结论未决；比较继续收集数据能否改变动作和剩余资源，不宣称等效或失败 |
| 出现不可接受负担或潜在伤害信号 | 按事前安全与审查流程暂停或调整；不等待主要终点“显著”才响应 |
| 获得足够资源，且真正的决定转为“是否保留结构化内容” | 首选翻转为加入等接触量比较的设计；明确新增成本和所需精度，针对 H1/H2 而非重复同一两组比较 |

冻结记录应保留方案版本、工具与计分版本、常规支持定义、阈值及制定者、预测和日期。新结果登记为独立 E# 并注明同源队列；同一患者的自报与任务数据不能算两次独立验证。更新时只重审受影响的判断和决定，记录原预测在哪失效。所有经验仅限于所研究病种、服务条件和测量范围，未经独立确认不外推到全部护理人群。
