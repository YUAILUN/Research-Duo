# 评审用量规（不要发给待测执行者）

每维 0–2 分：0=缺失/错误，1=识别但不可落实或局限未说清，2=正确且与当前决定、证据及动作明确连接。分开报告各维，不让一个总分掩盖关键科研错误。

| 维度 | 2 分要求 |
| --- | --- |
| 问题与识别 | 正确区分问题类型，识别设计无法支持的主张，并提出可回答的重构 |
| 证据忠实 | 不新增虚构资料；处理同源、反证、适用范围和未知 |
| 假设与实验 | 不同解释给不同预测，实验能区分，包含关键对照与解释限制 |
| 决策质量 | 必要条件先行，价值/概率分开，分支动作及停止条件可用 |
| 稳健与更新 | 关键翻转条件、失效证据影响范围、范围外使用边界明确 |
| 效率 | 有明确首要下一步，细节与任务相称，无多余角色表演/伪精确 |

关键错误单列：编造来源/概率、把相关当识别、泄漏后仍称可部署、把先导显著性当确证、把角色多数当独立证据、把合成数据当真实发现、算式或单位错误、未知强制归类。存在此类错误时不能以高总分宣称任务通过。

## 案例预期与反例

- RD01：方法与实验室混杂；优先考虑测量可比性及实验室内比较；不能凭均值差推广，不编造样本量。
- RD02：E1/E2/E3 是同一证据链；保留 E4 反证，核查测量/场景差异是否解释分歧；四个视角不等于四次重复。
- RD03：预测时点不可用特征与同人跨集合泄漏必须先修复；重新定义时间零点、拆分与验证；AUC 不能替代校准/使用价值。
- RD04：探索选择、多重指标、替代终点和先导目的需分开；设计独立确认与目标终点研究，不虚构功效。
- RD05：明确缺概率也缺量化效用，不能精确 EVSI；给条件策略/定性情景及最少关键输入，不能用任意效用数字伪装成已算稳健最优。
- RD06：检查测量滞后后比较撤除时间序列更能区分给定机制；加入无刺激/对照时序或可行替代以排除漂移；观测可支持/削弱假设但不穷尽全部机制。
- RD07：E1、E3 及 C1/J1/D1 需审查；撤回证据不等于主张为假；不相关 D2 不应被无故重写。
- RD08：基线最大 EU=0，EVPI=50，EVSI=30，净值25；阳性后推进 EU=60，阴性后延后 EU=0。假设输入须敏感性分析/验证；数值结果不是实际执行授权。

不要求固定措辞或唯一版式。更好的替代方案只要证据和推理可核实，应允许得分。
